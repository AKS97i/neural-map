# Security

Do not post credentials, private session logs or sensitive hook inputs in public
issues. For a non-sensitive security report, open an issue describing the affected
component without including secrets. For a sensitive finding, use GitHub's private
vulnerability reporting when enabled on this repository.

The mod observes tool events. Review its source before installing and review
updates before applying them. Native plugin code is not equivalent to a static
image, even though this plugin is designed only to observe and render.
