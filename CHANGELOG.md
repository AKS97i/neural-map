# Changelog

- Native Claude Code pane, derived from lot-map 0.9.0.
- Angular cyberpunk HUD with a static grid and quiet idle core.
- Night City, Netrunner, Arasaka, Monochrome and Classic color presets.

- Custom palette overrides and classic compatibility mode.
- Privacy, lifecycle, rendering and performance regression tests.
- Codex native integration documented as under investigation, not implemented.
